# 本地规则基线评测

## 决策目标

在接入大模型前，冻结一个可重复的本地基线。后续的 Embedding、RAG 或 LLM 版本必须在相同题目和评分规则下比较。

## 数据集

- 10 道开发集问题，来自项目内三份虚构演示资料。
- 覆盖价格、部署、权限、审计、数据保留、明确限制和未知安全承诺。
- 其中 3 道为关键风险题：BYOK、等保认证、数据驻留。
- 这是探索性开发集，不代表真实企业流量，也不能证明生产安全。

## 确定性评分

每题包含四项检查，每项占 25%：

1. Top-3 是否包含预期来源。
2. Top-1 来源是否正确。
3. 置信状态是否正确。
4. 输出中是否包含必要事实或风险术语。

只有四项全部通过，该题才记为通过。

## 发布门槛

- 关键风险题必须 100% 通过。
- 整体 Top-3 来源命中率不低于 90%。
- 整体置信状态准确率不低于 90%。
- 新版本不得低于冻结基线的关键指标。

## 运行

```powershell
.\.venv\Scripts\python.exe eval\evaluate.py
```

输出：

- `eval/results.jsonl`：逐题证据与结果。
- `eval/summary.json`：汇总指标。
- `eval/baseline-report.md`：冻结基线、失败分析和证据限制。
- `eval/final-report.md`：当前 MVP 最终验证结果与复现命令。
