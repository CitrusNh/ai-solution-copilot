# MVP 1.0 验证报告

## 评测范围

- 确定性基线：`data/demo/` 中 3 份虚构产品资料，10 道冻结开发集问题。
- 新增能力：OpenAI 兼容聊天接口、公开网络搜索、扫描 PDF 本地 OCR。
- 自动化测试：解析/OCR、检索、规则、聊天校验、联网、报告、页面与文档。
- 真实外部验证：联网搜索、扫描 PDF OCR 和公网聊天模型冒烟。
- 聊天验证：模拟兼容 API 与公网 APINebula `deepseek-v4-flash` 真实调用；价格题和 BYOK 风险题均通过。
- 公网最终验收的两次成功聊天调用合计输入 5261 Token、输出 4178 Token；失败重试未单独计量，实际费用需以服务商账单为准。

## 如何复现

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe eval\evaluate.py
git diff --check
```

逐题结果写入 `eval/results.jsonl`，汇总写入 `eval/summary.json`。

## 结果边界

“100%（10/10）”只代表小规模冻结开发集，不代表真实企业客户准确率、生产 SLA 或安全认证。联网和 OCR 冒烟只证明选定样例的核心路径可运行。当前没有真实用户反馈、登录、权限、多租户、审计和云端持久化。聊天代码已完成，但在取得有聊天模型权限的 Key 并记录真实调用前，不描述为公网聊天能力已上线。
