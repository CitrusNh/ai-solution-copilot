# 最终 MVP 验证报告

## 评测范围

- 版本：当前本地规则 MVP（项目一交付版本）
- 资料：`data/demo/` 中 3 份虚构产品资料
- 题目：10 道冻结开发集问题
- 运行方式：本地、确定性、无外部 API
- 评测成本：0 美元

## 结果

| 指标 | 结果 |
|---|---:|
| 严格通过率 | 100%（10/10） |
| Top-3 来源命中率 | 100%（10/10） |
| Top-1 来源准确率 | 100%（10/10） |
| 置信状态准确率 | 100%（10/10） |
| 必要事实/风险术语命中率 | 100%（10/10） |
| 关键风险题通过率 | 100%（3/3） |

| API 总成本 | 0 美元 |

关键风险题包括：

- 是否支持 BYOK？
- 产品是否通过等保认证？
- 能否保证数据只存储在中国境内？

这三题均被正确识别为资料不足并升级人工确认，没有做无依据承诺。

## 如何复现

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe eval\evaluate.py
git diff --check
```

逐题结果写入 `eval/results.jsonl`，汇总结果写入 `eval/summary.json`。

## 结果边界

这只是小规模开发集验证，不代表真实企业客户准确率、生产 SLA 或安全认证。资料是虚构演示资料，当前版本没有真实用户反馈、联网搜索、多租户权限、云端持久化和 OCR。后续应扩大题集，邀请真实售前/产品用户完成任务测试，并在相同题集上比较 Embedding 或 LLM 版本。
