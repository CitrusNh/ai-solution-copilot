# 项目经历与作品集材料

## 简历一行版

**AI 企业研究与售前方案助手｜Python、Streamlit、TF-IDF、PDF 解析、GitHub、Streamlit Cloud**
面向 B2B AI/SaaS 售前场景，独立完成从产品定义、资料解析、可解释检索到带来源方案草稿的可运行 MVP；针对 BYOK、等保和数据驻留等未知安全需求加入证据阻断与人工确认机制，冻结 10 道评测题并实现 10/10 通过，26 项自动化测试通过，部署公网 Demo。

## 简历两行版

- 将多份产品说明、价格和安全 FAQ 解析为可检索资料片段，使用字符级 TF-IDF 与业务意图加权完成中文检索，并展示来源、匹配分数和原文证据。
- 设计句子级相关性过滤、风险识别、追问清单、Markdown 报告和本地反馈闭环；对 BYOK/等保/数据驻留等未承诺能力不做无依据承诺，公网 Demo 可直接访问。

## 面试展开版

这是一个面向 B2B AI/SaaS 售前和解决方案顾问的知识检索产品。售前人员收到客户关于价格、部署、安全或功能的问题后，可以上传产品资料并获得四部分结果：可确认能力、限制与风险、需要继续向客户确认的问题，以及带来源的回复草稿。

我没有一开始就调用大模型，而是先做了一个可解释、零 API 成本的本地基线。这样可以把“资料是否被找对”“未知需求是否被正确转人工”“Top-1 来源是否正确”等指标冻结下来，再判断 Embedding 或 LLM 是否值得引入。当前版本用 10 道开发集和 26 项自动化测试验证，公网版本使用虚构演示资料。

## 量化结果的正确表述

- “10/10 通过”指项目内冻结的 10 道开发评测题，不等于真实客户准确率。
- “26 项测试通过”指本地自动化测试，不等于生产环境稳定性证明。
- “公网 Demo”指可公开演示的 Streamlit 应用，不支持登录、权限、云端持久化或企业机密资料。
- 真实用户反馈目前仍待收集，面试时应主动说明这一限制和下一步计划。
