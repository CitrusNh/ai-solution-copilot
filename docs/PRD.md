# AI 企业研究与售前方案助手

## 1. 产品定位

面向 B2B AI 公司的初级售前、解决方案顾问、产品运营和行业研究人员，帮助他们从产品资料中快速形成可核验的客户需求分析和售前方案草稿。

## 2. 用户痛点

- 产品资料分散，查找耗时。
- 客户需求难以快速映射到产品能力。
- 售前回复依赖个人经验，容易遗漏限制条件。
- 结论缺少来源，难以复核和交接。

## 3. MVP 用户流程

1. 上传产品说明、FAQ、价格与安全资料。
2. 解析并切分文档。
3. 输入客户需求。
4. 检索相关内容并生成结构化结果。
5. 展示来源引用、能力缺口、追问清单和售前回复草稿。
6. 用户下载 Markdown 分析报告。
7. 用户对结果进行有用/部分有用/无用评价，反馈仅保存在本机。

## 4. MVP 输出结构

- 需求摘要
- 客户关键痛点
- 产品匹配功能
- 证据与原文来源
- 当前能力缺口
- 需要继续询问客户的问题
- 售前回复草稿
- 风险提示

## 5. 暂不实现

联网搜索、多用户权限、计费系统、模型微调、语音功能和复杂后台。

## 6. 初步成功指标

- 20 道标准问题上的回答正确率达到 80% 左右。
- 关键结论来源覆盖率达到 90% 左右。
- 中位响应时间控制在 15 秒以内。
- 至少 3 名真实用户完成测试。
- 用户平均有用性评分达到 4/5。

## 7. 当前验证结果

- 冻结 10 道开发评测题，严格通过率 100%。
- Top-3 来源命中率、Top-1 准确率、置信状态准确率均为 100%。
- BYOK、等保和数据驻留 3 道关键风险题全部通过。
- 26 项自动化测试通过（包含作品集文档一致性检查）。
- 当前本地规则版本 API 成本为 0。
