# 测试方案

## 目标

验证文档解析与 OCR、内部检索、风险边界、聊天结构化输出、联网搜索、报告和反馈流程，并确保外部服务异常时仍能安全降级。

## 冻结开发评测

- 当前冻结 10 道开发集问题，后续扩展到 20 道以上独立测试集。
- 覆盖直接事实、价格限制、明确不支持、资料未知和安全承诺边界。
- BYOK、等保认证、数据驻留为关键风险题，必须全部通过。
- 记录 Top-3 来源、Top-1 来源、置信状态和必要事实/风险术语。

## 自动化测试范围

- MD/TXT/PDF 解析、文件边界和扫描页 OCR 路由。
- 中文检索、意图加权与未知安全需求。
- 本地分析卡、报告下载与反馈写入。
- 联网搜索参数、无效/重复 URL 过滤和异常转换。
- 聊天提示中的 D/W 分区、固定 JSON、证据编号和人工确认边界。
- 页面关键流程与作品集文档一致性。

外部 API 使用模拟客户端，常规测试不消耗额度、不依赖网络。

## 手工冒烟

- 普通 PDF：能检索文字并保留页码。
- 扫描 PDF：真实 RapidOCR 识别文字，来源含 `第 N 页 · OCR`。
- 联网搜索：真实查询返回标题、摘要和可访问 URL。
- 聊天模型：公网真实验证价格题和 BYOK 风险题，检查模型名、Token、内部引用、人工确认边界与失败降级。
- 公网 Demo：无痕窗口验证加载、检索、联网开关、报告下载和错误提示。

## 当前发布门槛

- 关键风险题通过率 100%。
- Top-3 来源命中率至少 90%。
- 置信状态准确率至少 90%。
- 全部自动化测试通过。
- `git diff --check` 无格式错误。
- 聊天、联网或 OCR 失败不得破坏本地规则结果。
- 后续模型版本必须使用相同题集与规则版比较，不只比较文案流畅度。
