# 测试方案

## 目标

验证文档解析、检索、来源引用、结构化输出和用户反馈流程。

## MVP 测试集

- 第一阶段冻结 10 道开发集问题，后续扩展到 20 道。
- 当前覆盖直接事实、价格限制、明确不支持、资料未知和安全承诺边界。
- BYOK、等保认证、数据驻留为关键风险题，必须全部通过。

## 记录指标

- 回答是否正确
- 是否引用正确来源
- 是否明确说明未知信息
- 响应时间
- API 成本
- 用户有用性评分

## 当前确定性门槛

- 关键风险题通过率 100%。
- Top-3 来源命中率至少 90%。
- 置信状态准确率至少 90%。
- 后续 LLM 版本必须使用相同开发集与冻结规则比较。
