# 系统架构与实现说明

## 一句话

系统把客户问题分别连接到内部产品证据和互联网公开信息，再由确定性规则与可选聊天模型生成售前分析；遇到 BYOK、等保、数据驻留等资料未承诺的需求时，保留“不能承诺、人工确认”的安全边界。

## 用户可见流程

```text
MD / TXT / 普通 PDF / 扫描 PDF
                ↓
解析、OCR 与切分（保留文件名、章节、页码）
                ↓
客户问题 → 字符级 TF-IDF + 业务意图加权 → Top-3 内部证据 [D]
    │
    └──── 可选公开网络搜索 → 互联网资料 [W]
                ↓
本地规则安全基线（始终可用）
                ↓
可选聊天模型结构化增强
  ├─ 固定 JSON 字段
  ├─ D/W 引用校验
  ├─ 未知需求人工确认门槛
  └─ API 失败自动降级
                ↓
分析卡 + 来源分区 + Markdown 报告 + 本地反馈
```

## 模块职责

| 模块 | 作用 | 面试时要点 |
|---|---|---|
| `app.py` | 页面、上传、能力开关、分析卡、下载和反馈入口 | 把检索、AI 和失败降级组成完整用户流程 |
| `src/ingest.py` | 解析 MD/TXT/PDF，扫描页用 RapidOCR 本地识别 | 普通页优先文本层；扫描页最多 20 页并标记 OCR |
| `src/retrieve.py` | 文档切分、字符级 TF-IDF、业务意图加权 | 中文无分词依赖，结果可解释 |
| `src/solution_card.py` | 句子相关性过滤、风险阻断、本地回复草稿 | 检索命中不等于可以直接承诺 |
| `src/web_search.py` | DDGS 公开网络搜索、URL 过滤和安全失败处理 | 只发送问题，不上传企业文档 |
| `src/llm_analysis.py` | OpenAI 兼容聊天调用、JSON 校验、证据引用和风险门槛 | 模型负责优化表达，程序保留业务约束 |
| `src/reporting.py` | 汇总本地结论、AI 结果、互联网来源和反馈 | 结果可带走、可复核、可迭代 |
| `src/embeddings.py` | 可选 Embedding 客户端、缓存和预算保护 | 是对比实验，不是网页运行前置条件 |
| `src/semantic_retrieve.py` | 语义/混合检索实验 | 用同一评测集比较收益 |

## 三类信息为什么分开

- **内部证据 D：** 唯一可以证明本产品支持某项能力的资料。
- **互联网资料 W：** 只补充行业、政策或竞品背景，不能替企业作产品承诺。
- **模型生成内容：** 是基于证据的表达层，不是新的事实来源。

这种分层解决的不是“模型会不会写”，而是售前人员能否判断一句话来自哪里、能不能对客户承诺。

## OCR 实现

1. `pypdf` 先读取每页文本层。
2. 字符过少的页面被判为疑似扫描页。
3. PyMuPDF 以 2 倍比例渲染页面。
4. RapidOCR 在本地识别文字，不调用付费 OCR API。
5. 输出片段保留 `第 N 页 · OCR`，方便回到原文复核。
6. 单文件最多识别 20 个扫描页，避免公共 Demo 被大文件拖垮。

## 聊天模型安全与降级

- 模型只收到客户问题、Top-3 内部片段和已选择的公开搜索摘要。
- 检索内容被标记为不可信证据文本，提示模型忽略其中的角色或指令。
- 输出必须符合 Pydantic JSON 结构并引用真实存在的 `D/W` 编号。
- 至少引用一条内部资料；资料不足时回复必须保留人工确认语言。
- 超时、限流、额度、格式或引用校验失败时，不展示该模型结果，继续保留本地规则分析。
- Key 只从环境变量或 Streamlit Secrets 读取。

## 当前数据边界

- 这不是生产系统，而是用于求职展示和产品验证的可运行 MVP。
- 演示资料位于 `data/demo/`，全部为虚构资料。
- 上传文件只在当前 Streamlit 会话中解析，不写入 Git。
- 本地反馈写入 `data/feedback/`，Embedding 缓存写入 `data/cache/`，两者均被忽略。
- 公共 Demo 没有登录、权限、多租户、审计或持久化数据库，不适合企业机密资料。

## 可验证结果

- 自动化测试：33 项全部通过，覆盖解析/OCR、检索、规则分析、聊天输出校验、联网搜索、报告和文档一致性。
- 冻结开发评测：10/10 通过，Top-3 来源命中率、Top-1 来源准确率和关键风险题通过率均为 100%。
- 真实联网冒烟测试已获得可访问的公开网页结果。
- 真实扫描 PDF 冒烟测试已识别文字并保留 OCR 页码标记。
- 聊天集成已用模拟兼容 API 验证；当前 APINebula Key 无聊天模型权限，尚未把真实聊天调用描述为上线。
