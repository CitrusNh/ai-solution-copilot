# 3 分钟演示脚本

## 开场（约 20 秒）

“这是一个面向 B2B AI/SaaS 售前和解决方案顾问的企业资料分析助手。它不是开放式聊天机器人，核心目标是把客户问题、内部产品证据和可验证结论连接起来，减少查资料时间和无依据承诺。”

## 场景一：未知安全需求（约 45 秒）

1. 输入 `是否支持 BYOK？`。
2. 展示 `资料不足，需要人工确认`。
3. 指出内部证据来自 `security_faq.md`，系统不会拿通用能力或互联网资料证明支持 BYOK。
4. 展示追问清单和回复草稿。

讲解：“在售前场景里，正确拒绝无依据承诺比生成一段肯定答案更重要。”

## 场景二：联网公开研究（约 40 秒）

1. 输入一个需要公开背景的问题并勾选“联网搜索公开资料”。
2. 生成分析后滚动到“互联网公开资料”。
3. 指出每条结果都有标题、摘要和可打开 URL，并与内部证据分区。

讲解：“联网只发送客户问题，不上传企业文档。公开资料只能补充背景，不能替企业承诺产品能力；搜索失败时本地分析仍能工作。”

## 场景三：扫描 PDF OCR（约 40 秒）

1. 上传准备好的扫描版测试 PDF。
2. 展示“来自扫描页 OCR”的提示。
3. 查询扫描件中的关键词，并指出来源标记 `第 1 页 · OCR`。

讲解：“系统先尝试读取 PDF 文本层，字符过少的页才转成本地 OCR，既兼顾速度，也保留页码供人工复核。”

## 场景四：聊天模型与安全基线（约 45 秒）

有聊天 Key 时：

1. 勾选“使用聊天模型增强分析”。
2. 展示固定结构的 AI 摘要、回复、风险、追问、模型名和 Token。
3. 对比本地规则卡与 AI 表达。

公网 Demo 当前已配置聊天模型。推荐先演示价格题，再演示 BYOK，说明同一个模型既能优化表达，也必须服从内部证据和人工确认门槛。

没有聊天 Key 时：

“聊天接口、固定 JSON 校验、引用检查和失败降级已经完成，但当前 API Key 没有聊天模型权限，所以公网版保持关闭。我不会把模拟测试描述为真实上线；本地规则基线仍然完整可用。”

## 收尾（约 30 秒）

“项目冻结了 10 道开发评测题，当前 10/10 通过，并有 39 项自动化测试。联网、真实扫描 PDF OCR 和公网聊天模型均已完成冒烟验证。下一步不是继续堆功能，而是找 3 名目标用户测试，记录任务用时、人工修改率和错误承诺风险，再决定聊天模型带来的收益是否值得成本。”
